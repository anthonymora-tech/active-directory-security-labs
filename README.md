# 🔐 Active Directory Security Lab Series

This repository documents my hands-on Active Directory security lab environment built to simulate real-world enterprise identity infrastructure.  
The goal of this project is to develop practical experience in domain administration, security hardening, and incident response workflows.

---

## 🧠 Lab Environment Overview

- **Domain Controller:** Ubuntu Server running Samba AD DC
- **Client Systems:** Windows 11 Enterprise VM joined to domain
- **Domain Name:** lab.local
- **Infrastructure:** Virtualized homelab environment
- **Focus Areas:** Identity security, authentication controls, policy enforcement

---

## 🧪 Lab Objectives

✔ Deploy and configure Active Directory domain services  
✔ Join Windows systems to the domain  
✔ Implement domain security policies  
✔ Enforce password complexity and lockout protections  
✔ Validate authentication behavior and access control
